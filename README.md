# BBC Scroll Unlock

A tiny Chrome extension that removes the Piano subscription/offer overlay on [bbc.com](https://www.bbc.com) news articles and restores page scrolling when it gets stuck.

## What it does

BBC News articles sometimes show a modal (built on a widget called Piano) prompting a subscription or offer. Occasionally the modal's scroll-lock outlives the modal itself, leaving the page unscrollable even after the overlay is gone. This extension:

- Removes the Piano modal (`.tp-modal`) as soon as it appears
- Undoes the `position: fixed` / `overflow: hidden` scroll-lock trick some sites use
- Strips common scroll-lock CSS classes left behind on `<html>`/`<body>`
- Blocks stray `wheel`/`touchmove` listeners that try to cancel scrolling

It runs automatically on every `bbc.com` page load — no button to click.

**Note:** this bypasses BBC's own subscription/offer prompt rather than fixing a bug. Use it if you just want your scrolling back and don't mind skipping that prompt.

## Get the extension

This repo is published via GitHub Pages. Visit the live page and click the download button to get `bbc-scroll-unlock.zip`, containing:

- `manifest.json` — the Chrome extension manifest (Manifest V3)
- `unlock.js` — the content script that does the actual work

## Installing in Chrome

1. Download and unzip `bbc-scroll-unlock.zip`. Keep `manifest.json` and `unlock.js` together in one folder.
2. Go to `chrome://extensions` (Edge: `edge://extensions`).
3. Turn on **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the unzipped folder.
5. Done — visit any `bbc.com` article and the extension runs automatically.

Works the same way in Edge, Brave, and other Chromium-based browsers. Firefox and Safari need different loading steps (Firefox: temporary add-on via `about:debugging`; Safari: requires packaging as a Safari Web Extension via Xcode).
