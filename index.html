BBC Scroll Unlock

A tiny Chrome extension that strips the Piano paywall/offer overlay on bbc.com and restores page scrolling if it gets stuck.

1. Download the extension files

2. Install it in Chrome

  1. Unzip the file. You should end up with a folder containing two files: manifest.json and unlock.js. Keep them together in one folder — don't move them apart.
  2. Open the extensions page. In Chrome, go to chrome://extensions (paste that into the address bar). Edge users can use edge://extensions the same way.
  3. Turn on Developer mode. There's a toggle for it in the top-right corner of the extensions page.
  4. Click "Load unpacked". A file picker will open — select the folder from step 1 (the one containing manifest.json).
  5. Done. The extension is now active. Visit a BBC News article — if the Piano subscription overlay appears and blocks scrolling, this extension removes it and restores scroll automatically, no click needed.
Note: this disables BBC's own subscription/offer prompt (built on a widget called Piano) rather than fixing a bug — worth knowing since it's a deliberate bypass of that prompt, not a glitch fix.
